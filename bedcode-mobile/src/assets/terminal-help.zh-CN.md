# 终端输入便捷功能指南

移动端输入组件集成了完整便捷功能：快捷键面板、自定义快捷键、自定义命令、Agent 命令预设、`/` 补全与 `@` 文件引用。本文档逐一说明用法。

## 输入条总览

输入条位于终端底部，由三部分组成：

- **快捷条（Quick Bar）**：常驻显示最常用的快捷键与命令（按使用频次自动排序），点击即发送
- **输入框**：输入指令，支持多行（聚焦展开至 3 行，最多 6 行）
- **操作按钮**：快捷键面板开关、发送（文本不带回车）、执行（文本 + Enter）

> 发送与执行：**发送** = 文本进入终端输入行但**不回车**（适合 skill 前缀补全等场景）；**执行** = 文本 + Enter 直接运行。

## 快捷键面板

点击输入条左侧的网格图标打开。面板**左右滑动**切换两页：

| 页面 | 内容 |
|------|------|
| 第一页 | 一般快捷键 + Enter/Del + 方向键（键盘布局） |
| 第二页 | Agent 命令预设（builtin，不可删）+ 自定义命令 |

- 点击底部圆点可快速切换页面
- 顶部圆点高亮当前页，滑动循环（第一页右滑到第二页，反之亦然）
- 横屏模式下面板不可用（提示而非静默无响应）

### 快捷键功能表

| 按键 | 功能 |
|------|------|
| Tab | 自动补全命令、文件名或路径 |
| Enter | 执行当前输入 |
| Esc | 中断当前运行进程（同 Ctrl+C 的 SIGINT 场景）/ 取消 |
| Del | 删除光标前一个字符 |
| Ctrl+C | 发送 SIGINT 中断信号 |
| Ctrl+Z | 挂起当前进程（`fg` 恢复） |
| Ctrl+L | 清屏 |
| ↑ ↓ ← → | 历史导航 / 光标移动 |

## 自定义快捷键

终端顶栏的「快捷键」按钮打开**快捷键配置弹窗**，两个标签页：

- **列表页**：管理内置/自定义快捷键——切换显示/隐藏、删除自定义项、一键恢复默认
- **添加页**：通过键盘捕获（点击捕获框直接按键）或按键网格（修饰键 + 字母/数字/功能键/编辑键/方向键）组合新快捷键

添加后快捷键立即生效，可出现在第一页与快捷条。

## 自定义命令

快捷键面板第二页点击 **+** 添加自定义命令（输入文本即可）：

- 添加后与预设命令一起展示，点击即执行（文本 + Enter）
- 编辑模式（铅笔按钮）：删除自定义命令（预设命令 builtin 不可删除）
- 自定义命令持久化到本地（settings DB），重启不丢
- 使用频次会统计，高频命令自动进入快捷条

## Agent 命令预设

面板第二页前半部分是**当前会话自动识别的 Agent CLI 命令集**：

- 支持 Claude Code / pi / Codex / OpenCode 四套预设（每套 12 条）
- 识别依据：会话配置的启动命令关键词（claude / pi / codex / opencode）
- 识别为未知（generic）时第二页只显示自定义命令
- 预设命令带 builtin 标记，不可删除；以「发送」模式执行的项（如 `/`、`/skill:`）点击后填充输入行，补全后由你决定提交

## `/` 命令补全

输入框内输入 `/` 时弹出**本地命令补全列表**（复用预设数据，零延迟）：

- 前缀过滤（如 `/co` → `/compact`、`/cost`）
- 点选即填充输入框，保持焦点，由你决定补全或发送
- 会话未识别 Agent（generic）时不弹出
- 用户开始打字时补全层自动收起

## @ 文件引用

文件侧栏（顶栏「文件夹」按钮）中：

- **点按文件**：打开文件查看内容
- **长按文件**：复制文件路径，并自动以 `@路径` 形式填入输入框（自动收起侧栏并聚焦输入框，已有内容时补空格分隔）
- agent CLI（Claude Code 等）会解析 `@路径` 引用文件

## 中断与清理

- **中断生成**：快捷键面板第一页 **Esc**（等价特殊键通道）
- **清屏**：顶栏清屏按钮或快捷键面板 Ctrl+L
- 输入框内打断 prompt：输入内容在会话切换前保留（草稿由你确认后再发）

## 常见问题

- **第二页看不到 Agent 命令**：确认会话配置启动命令包含 claude / pi / codex / opencode 关键词；通知直达终端页时会话数据稍后才就绪，稍等片刻或重新进入
- **面板与补全层重叠**：开始输入时面板自动收起，避免遮挡
