# 终端快捷键参考

移动端终端模拟了桌面终端的常用快捷键，以下是各快捷键在终端中的功能说明。

## 输入栏

终端底部为输入栏，自下而上依次为：输入框、操作按钮、快捷栏。

### 快捷栏

- 常驻显示高频快捷键与快捷命令，按使用频次从高到低自动排列（横向可滑动查看更多）
- **Enter / Del 固定显示在最右侧**：不参与频次排序，始终可见，方便拇指高频操作
- 点按即发送对应按键/命令到终端

### 输入框操作按钮

| 按钮 | 功能 |
|------|------|
| 滑块按钮 | 展开/收起快捷键面板（含快捷键、方向键与自定义命令，左右滑动切换页面） |
| 发送按钮（↑） | 将输入内容发送到终端输入行（不带回车） |
| 执行按钮（纸飞机） | 执行输入内容（自动追加回车，如执行命令） |

### 文件侧边栏（引用文件）

终端侧栏打开文件树后：

- **点按文件**：打开文件查看内容
- **长按文件**：复制文件路径，并自动以 `@路径` 形式填入输入框（无需再手动输入）

## 修饰键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+C | 发送 SIGINT 信号，中断当前运行的进程 |
| Ctrl+D | 发送 EOF（文件结束符），退出当前 Shell 或结束输入 |
| Ctrl+Z | 挂起当前进程（放入后台），使用 `fg` 恢复 |
| Ctrl+L | 清屏，等同于 `clear` 命令 |
| Ctrl+A | 将光标移动到行首 |
| Ctrl+E | 将光标移动到行尾 |
| Ctrl+K | 删除从光标到行尾的内容 |
| Ctrl+U | 删除从光标到行首的内容 |
| Ctrl+R | 反向搜索历史命令 |

## 基本按键

| 快捷键 | 功能 |
|--------|------|
| Tab | 自动补全命令、文件名或路径 |
| Enter | 执行当前输入的命令 |
| Esc | 取消当前输入 / 退出编辑模式 |
| Backspace | 删除光标前一个字符 |

## 方向键与导航

| 快捷键 | 功能 |
|--------|------|
| ↑ | 显示上一条历史命令 |
| ↓ | 显示下一条历史命令 |
| ← | 光标左移一个字符 |
| → | 光标右移一个字符 |
| Home | 光标跳到行首 |
| End | 光标跳到行尾 |
| Page Up | 向上翻页查看终端输出 |
| Page Down | 向下翻页查看终端输出 |

## 编辑键

| 快捷键 | 功能 |
|--------|------|
| Insert | 切换插入/覆盖模式 |
| Delete | 删除光标后一个字符 |

## 自定义快捷键

在快捷键配置中，你可以添加自定义快捷键组合。选择修饰键（Ctrl / Shift / Alt）加上一个按键即可创建。

自定义快捷键会直接发送对应的按键序列到终端，其功能取决于当前运行的程序。
