# 终端快捷键参考

移动端终端模拟了桌面终端的常用快捷键，以下是各快捷键在终端中的功能说明。

## 修饰键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+C | 发送 SIGINT 信号，中断当前运行的进程 |
| Ctrl+D | 发送 EOF（文件结束符），退出当前 Shell 或结束输入 |
| Ctrl+Z | 挂起当前进程（放入后台），使用 `fg` 恢复 |
| Ctrl+L | 清屏，等同于 `clear` 命令 |
| Ctrl+A | 将光标移动到行首 |
| Ctrl+E | 将光标移动到行尾 |
| Ctrl+K | 删除从光标到行尾的内容 |
| Ctrl+U | 删除从光标到行首的内容 |
| Ctrl+R | 反向搜索历史命令 |

## 基本按键

| 快捷键 | 功能 |
|--------|------|
| Tab | 自动补全命令、文件名或路径 |
| Enter | 执行当前输入的命令 |
| Esc | 取消当前输入 / 退出编辑模式 |
| Backspace | 删除光标前一个字符 |

## 方向键与导航

| 快捷键 | 功能 |
|--------|------|
| ↑ | 显示上一条历史命令 |
| ↓ | 显示下一条历史命令 |
| ← | 光标左移一个字符 |
| → | 光标右移一个字符 |
| Home | 光标跳到行首 |
| End | 光标跳到行尾 |
| Page Up | 向上翻页查看终端输出 |
| Page Down | 向下翻页查看终端输出 |

## 编辑键

| 快捷键 | 功能 |
|--------|------|
| Insert | 切换插入/覆盖模式 |
| Delete | 删除光标后一个字符 |

## 自定义快捷键

在快捷键配置中，你可以添加自定义快捷键组合。选择修饰键（Ctrl / Shift / Alt）加上一个按键即可创建。

自定义快捷键会直接发送对应的按键序列到终端，其功能取决于当前运行的程序。
