# Internationalization & Typography

CJK 项目（中文 + 英文）的字体策略、行高调整、RTL 准备。

> **何时加载**：编写多语言 UI、CJK 混排段落、自定义字体、或评估 RTL 支持时。

---

## Font Stack

CJK 字符宽度不一致，必须显式声明回退顺序。规则：**优先字体在左，回退字体在右**。

### 桌面端（英文优先）

```css
/* 全局已在 tailwind.config.js 的 fontFamily.sans 中声明 */
font-family: 'Inter', 'PingFang SC', 'Microsoft YaHei', system-ui, sans-serif;
```

### 移动端（中文优先）

```css
/* 移动 UI 默认中文为主，英文回退 */
font-family: 'PingFang SC', 'Inter', system-ui, sans-serif;
```

### 等宽字体（终端、代码、ID）

```css
/* 移动端 monospace 必须包含等宽 CJK 字体 */
font-family: 'JetBrains Mono', 'Cascadia Code', Consolas, Monaco,
             'Sarasa Mono SC',  /* 中文等宽，行业标准 */
             monospace;
```

### 规则

- 禁止单字体声明（必须带 `system-ui` / `sans-serif` / `monospace` 兜底）
- 自托管字体优先（避免 CDN 抖动导致 CLS）
- `font-display: swap`（避免 FOIT 白屏）

## Line Height Strategy

CJK 字符笔画密度高，需要更大行高避免视觉粘连。**中英混排时行高取较大值**。

| 内容类型 | 工具类 | 实际 line-height | 适用场景 |
|---------|--------|------------------|---------|
| 纯英文/数字 | `leading-tight` | 1.25 | 标题、单行标签 |
| 中英混排（默认） | `leading-normal` | 1.5 | 段落、列表项、表单 |
| 纯中文段落 | `leading-relaxed` | 1.625 | 长文阅读、设置说明 |
| 中文紧凑 | `leading-snug` | 1.375 | 移动端卡片正文 |

**Token 优先**：

```css
/* 文本容器使用 token（不写死数字） */
.text-body {
  line-height: var(--leading-body, 1.5);
}
.text-heading {
  line-height: var(--leading-heading, 1.25);
}
```

## Mixed-Language Pitfalls

### 1. 中英文之间自动加空格

中文排版惯例：中英文/数字之间需要**半角空格**分隔，提升可读性。

```html
<!-- ❌ 粘连 -->
<p>使用 Vue 3 + TypeScript 开发</p>

<!-- ✅ 习惯性加空格（也可用 i18n 字典统一处理） -->
<p>使用 Vue 3 + TypeScript 开发</p>
```

> **工程取舍**：i18n 字典中已规范的不需要重复加；纯展示文本由开发者手动控制。

### 2. 标点挤压

中文标点不应用 `font-feature-settings: 'palt'`（proportional alternates），**否则引号/逗号会变窄**，破坏对齐。

```css
/* 禁止全局启用 palt */
body { font-feature-settings: normal; }

/* 如需启用，仅在标题短文本中 */
.title { font-feature-settings: 'palt' 1; }
```

### 3. 数字字宽

- 表格数据用 **tabular-nums**（等宽数字）保证对齐
- 段落正文用 **proportional**（默认即可）

```css
.table-data {
  font-variant-numeric: tabular-nums;
}
```

## Logical Properties (RTL 准备)

如果未来需要支持阿拉伯语/希伯来语，**新代码优先用 logical properties**，避免后续批量替换。

| 物理属性（避免） | 逻辑属性（推荐） | Tailwind 等价 |
|----------------|------------------|--------------|
| `margin-left` | `margin-inline-start` | `ms-*` |
| `margin-right` | `margin-inline-end` | `me-*` |
| `padding-left` | `padding-inline-start` | `ps-*` |
| `padding-right` | `padding-inline-end` | `pe-*` |
| `text-left` | `text-start` | `text-start` |
| `text-right` | `text-end` | `text-end` |
| `border-l-4` | `border-s-4` | `border-s-4` |
| `border-r-4` | `border-e-4` | `border-e-4` |
| `left-0` | `start-0` | `start-0` |
| `right-0` | `end-0` | `end-0` |

### 现有代码迁移策略

- **新组件**：强制使用 logical properties
- **老组件**：保持物理属性，**不批量迁移**（成本高、收益小）
- **icon-only 按钮**：图片/图标本身需手动镜像（`transform: scaleX(-1)` 或换 SVG）

### 镜像例外

以下属性**不受 RTL 影响**，可继续用物理属性：

- `width` / `height`
- `top` / `bottom`
- `border-top` / `border-bottom`
- `margin-top` / `margin-bottom`
- `padding-top` / `padding-bottom`

## Font Loading

```css
/* 自托管字体，避免 CDN CLS */
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-var.woff2') format('woff2-variations');
  font-weight: 100 900;          /* 可变字体一次声明 */
  font-style: normal;
  font-display: swap;            /* 立即用 fallback，不阻塞渲染 */
  size-adjust: 100%;             /* 减少回流 */
  ascent-override: 90%;
  descent-override: 22%;
  line-gap-override: 0%;
}
```

**收益**：
- `size-adjust` / `ascent-override` 让 fallback 字体尺寸与 web font 接近，**减少 CLS**
- `font-display: swap` 避免 FOIT（不可见文本）阻塞首屏

---

## Checklist

新建多语言组件时：

- [ ] `font-family` 包含 CJK 回退栈
- [ ] 长段落使用 `leading-normal` 或 `leading-relaxed`
- [ ] 表格数字用 `tabular-nums`
- [ ] 间距使用 logical properties（`ms-*` / `me-*` / `ps-*` / `pe-*`）
- [ ] 自托管字体声明 `font-display: swap` + `size-adjust`
- [ ] 不全局启用 `palt`（中文标点挤压）
