#### 一、AGENTS（§5 / §7 / §8）

- **§5 无业务内核**：把「会话」从「逐步下沉 / 暂留宿主侧」的清单里**摘除并给终态结论**——
  会话真源在插件、宿主**零会话对象**（内核目录已删、`host-session` / `host-terminal` 已退役），
  宿主与会话相关的只剩三样无业务语义的东西（PTY 引擎 / 连接清单 / 窄转发层），并点名防回接锁。

  已在票 10 / 票 11 的提交里同步；本票复核 `ptyQuota` 与 PTY 三件套措辞未受影响。
- **§8 fail-visible**：保留为**通用判据**并拆成三种形态（宿主回查 / 旧 ABI 产物 / 退役权限位），
