# 08: 全链路压测与收口

**What to build:** 把这次重构的收益与边界用真机压测证实，并把结论固化回文档与常量——避免"改完了但没人知道水位该取多少"。

压测矩阵（桌面 + 移动端同时跑）：输出风暴（持续高吞吐）、移动端切后台、断网重连、回前台重进页面。观察点：桌面本地终端是否全程不卡顿、移动端重进页面历史是否完整、订阅者统计（lag / 驻留 / 截断 / 重同步）能否定位到具体订阅者。

**Blocked by:** 01 — 拉取模型订阅者（expand）；02 — 移动端 WS 订阅切到拉取模型；03 — 桌面本地终端订阅切到拉取模型；04 — 源侧去背压 + 旧机制下线；05 — Resync 协议（两端）；06 — 三段容量/水位预算对齐；07 — 移动端段2 合帧

**Status:** ready-for-agent

- [ ] 压测矩阵四项全过：桌面本地终端无卡顿、移动端重进页面历史完整、慢订阅者只影响自己、无僵尸误判
- [ ] 水位常量定稿（订阅者高/低水位、驻留轮询、僵尸超时、移动端 ack 阈值、段2 高/低水位）并回写 spec §8
