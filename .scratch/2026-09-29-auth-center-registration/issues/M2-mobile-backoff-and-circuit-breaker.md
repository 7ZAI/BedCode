# M2: 移动端自愈最小退避 + 同因熔断（纵深防御）

**What to build:** 即便桌面再出别的快速拒绝，移动端也不得打爆日志/toast。当前实测 6.3 Hz、零退避。

**Blocked by:** 无

**Status:** todo

- [ ] 自愈重连**最小退避下限 ≥1s**（现在成功路径无退避，只有失败路径有）
- [ ] **同因熔断**：连续 N 次（建议 5）同一 code+reason → 停止重连并上报（前端给一次性提示）
- [ ] 熔断后的人工恢复出口：用户手动重连 / 网络变化事件（`NetworkChange`）重置熔断
- [ ] 单测：退避下限生效；同因 N 次触发熔断；网络变化重置熔断

## 关键实现事实

- 这是**纵深防御**：票 03 修了根因，但任何未来的快速拒绝路径（别的 4xxx、别的 5xx 风暴）都会被这一层兜住
- 不改事件契约（`reconnecting` / `reconnected` / `reconnect_failed`），前端零改动
