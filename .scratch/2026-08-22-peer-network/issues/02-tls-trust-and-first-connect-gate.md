# 02 — TLS 直连 + 信任存储 + 首次连接确认闸门

**What to build:** 节点可单端口监听并接受拨号、可主动拨号对端；TLS 握手用自定义 verifier 校验对方证书指纹即节点 ID。信任层落地词汇表语义：本地持久保存可信对端节点 ID 列表；未信任方拨入时连接停在应用层确认闸门，宿主经回调收到确认请求——接受则双向建立信任并连通（后续重连静默），拒绝则本次失败可重试；指纹不在可信集的连接在 TLS 层被拒。全部行为在双节点 harness 上断言。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 未信任 A 拨 B：B 收到确认回调；拒绝 → A 连接失败；接受 → 连通且双方信任落库
- [ ] 已信任对端重连全程无确认回调
- [ ] 证书指纹与任何已知身份不符 → TLS 拒绝
- [ ] 信任列表撤销后重连重新走确认
- [ ] 撤销动作有 API 且落库持久
