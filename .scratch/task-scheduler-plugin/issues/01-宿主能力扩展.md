# 宿主能力扩展：host-process 接口 + 本地时间注入

Type: task
Status: ready-for-agent

> 规格依据：`.scratch/task-scheduler-plugin/spec.md` §7（执行引擎）、§5.1（本地时间）。实现前先读 `docs/adr/0017-plugin-inter-plugin-call-gate.md`（互调机制，本 issue 不涉及，但 04 号 issue 会用到）。

## 任务

计划任务插件需要两个宿主新能力：

1. **`host-process` WIT interface**（`bedcode-desktop/packages/plugin-sdk-desktop/rust/wit/bedcode.wit` 新增）：
   ```wit
   interface host-process {
       run: func(request-json: string) -> result<string, string>;  // 返回 run-id
       kill: func(run-id: string) -> result<_, string>;
   }
   ```
   - request-json：`{ command, args, cwd, env, timeout_ms, output_path }`
   - **异步执行 + 事件回调**（沿用 `session_create` → Created 事件模式）：run 立即返回 run-id，进程结束后宿主分发完成事件（exit_code / timeout 标记）
   - 宿主实现（`src-tauri/src/plugin/wasm_runtime/host_impl/` 新增 `process.rs`）：`tokio::process::Command`，超时 `tokio::time::timeout` + kill 进程组（含子进程）；stdout/stderr 边跑边写 output_path（宿主侧直接写文件，不经 WASM 内存）
2. **本地时间注入**：调度 tick 需要本地时区基准（规避 WASM 无时钟 + DST 漂移）。方案：`timer_register` 回调参数追加 `now_local`（宿主 Rust 侧 `chrono::Local` 格式化 `YYYY-MM-DD HH:MM:SS`），或新增 `host-clock` interface 提供 `local-now()`——实现者二选一，推荐前者（改动最小，现有 timer 已注入 `now_ms`/`now_utc`）
3. **权限键**：新增 `PERMISSION_PROCESS`，宿主 `check_permission` 门禁；manifest 声明即信任

## 验收标准

- [ ] WIT 编译通过，SDK `WasmHost` 接线（`wasm_host.rs` 实现 host-process trait）
- [ ] 宿主单测：run 正常退出（exit_code）、非零退出、超时 kill（含子进程）、output_path 内容完整、权限拒绝路径
- [ ] timer 回调注入 `now_local`（或 host-clock 可用），格式与 SQLite `datetime('now')` 一致
- [ ] `cargo test` 全绿
