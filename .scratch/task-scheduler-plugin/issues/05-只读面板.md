# 桌面端只读面板：任务列表 + 最近执行 + 日志

Type: task
Status: ready-for-agent

> 规格依据：`.scratch/task-scheduler-plugin/spec.md` §10。依赖 02 号 issue（端点 + 事件广播）。

## 任务

1. **Vue 组件**（`plugins/task-scheduler/src/components/SchedulerPanel.vue` 或等价）：
   - 任务列表：name / schedule / enabled / next_at / 最近执行摘要（状态徽标：succeeded/failed/timeout/missed/waiting/running）
   - 选中任务：最近执行记录列表（trigger / 时间 / exit_code）+ 输出文件路径（可复制）
   - **只读**：无 CRUD 表单（CRUD 全走 CLI）
2. **实时刷新**：订阅 `emit_event` 三通道广播（`EVENT_TASK_SCHEDULED_CHANGED` 模式：broadcast_sync + bus + emit_event），事件到达刷新列表；初始加载走 list/logs 端点
3. **入口**：插件挂载方式与现有插件一致（桌面端插件页/侧栏入口，参照 auto-task 桌面端组件挂载模式）
4. **样式**：遵循 `frontend-styles` skill 的 token 体系；状态色与 auto-task 面板状态色系一致

## 验收标准

- [ ] 列表/执行记录/日志路径展示正确；CLI 侧变更（add/disable/run）后面板实时刷新
- [ ] 空态、enabled=false 态、错误态（桌面端网关异常）有明确展示
- [ ] 前端 `npm run test:run` 通过
