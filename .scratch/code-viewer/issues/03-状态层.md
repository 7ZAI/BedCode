## 任务

新增 `src/composables/useCodeViewer.ts`——纯逻辑层，UI 组件只负责渲染（AGENTS.md：业务放 composables）：

1. **状态**：`root`（锚点目录）/ `tabs: CodeTab[]` / `activeTabId` / `showHidden`（dotfiles 开关）/ `treeCache: Map<dirPath, CodeDirEntry[]>`（懒加载缓存 + 手动刷新失效）
2. **根目录锚定**：默认取当前会话 `workingDir`（`SessionInfo.workingDir`，见 `src/composables/model.ts`）；提供 `setRoot(dir)`（文件夹切换）；不跳 git 根
3. **持久化**：localStorage 按 sessionId 隔离（key 含 sessionId）：root / tabs / activeTabId；恢复时对新 root 做存在性校验（失效则回退默认）
4. **标签**：`openFile`（上限 16，超出返回拒绝提示）/ `closeTab` / `closeActiveTab` / `setActiveTab` / `clearAll`；同文件重复打开聚焦既有标签
5. **自动重载**：活动标签文件 mtime 轮询（`setInterval` ~1s，经 `stat_code_file`），mtime 变化 → 重新 `read_code_file` 刷新视图内容；轮询仅活动标签（术语「自动重载」）
6. **打开流程**：文件 size > 1MB 或行数超 2 万 → 不打开，返回「文件过大」原因（前端提示）
7. **窗口生命周期**：composable 挂在终端窗口页面内（每窗口实例独立）；卸载时清理 interval
