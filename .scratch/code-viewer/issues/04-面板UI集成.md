# 04 面板 UI 集成：组件 + 工具栏 + 布局

Type: task
Status: ready-for-agent
Blocked by: 02, 03

> 规格依据：`.scratch/code-viewer/spec.md` §1–§3、§6–§9、§14–§19。**动手前必读 `frontend-styles` skill 并以之为准**（AGENTS.md 强制）。i18n key 在本 issue 一并落地双端。

## 任务

1. **组件**（`src/components/`，全部 `<script setup lang="ts">`）：
   - `CodeViewerPanel.vue`：左右容器（左 FileTree / 右 标签条 + CodeViewer）；空态引导（未选根/空树）；加载/错误态
   - `FileTree.vue`：懒加载（经 03 的 treeCache）、单击目录展开收起 / 单击文件打开标签（VS Code 风格）、dotfiles 隐藏开关、手动刷新按钮、树内加载指示
   - `CodeTabs.vue`：切换 / × 关闭 / 中键关闭 / 溢出水平滚动 / 上限 16 提示气泡
   - `CodeViewer.vue`：行号 + `highlight.js` core 按需加载（≈15 常用语言：js/ts/vue/html/css/json/rust/python/shell/markdown/yaml/toml/go/java/sql…）、wrap 开关、独立字号（复用 wb-mono + `--ui-scale` 体系）、Ctrl+F 搜索条（高亮匹配/计数/下一个）、大文件「仅显示前 N 行」提示、「文件过大不自动打开」提示、自动重载中骨架/静默刷新
2. **接线**：`TerminalWindowView.vue` header 增加代码面板按钮（展开/收起图标态）；布局展开态：终端容器宽度钉死为展开前视口宽度、面板 flex 占余（ADR 0023：终端视口像素尺寸不变）；收起移除面板
3. **窗口几何**：调用 02 的 `toggleCodePanel`；拒绝展开（屏余 < 300）时 toast 提示
4. **依赖**：`highlight.js` 安装（core + 按需语言 import）
5. **i18n**：`src/locales/zh-CN.ts` + `en.ts` 同步新增（`desktop.terminal.*` 下）：open/close code viewer、文件过大、超过标签上限、显示隐藏文件、刷新、空态引导、搜索占位/无结果、拒绝展开提示 等；「文件过大」等文案与 03 返回的原因码一致

## 验收标准

- [ ] 展开态终端视口像素宽度不变（dev 手动验证：展开前后 xterm 无 PTY resize）
- [ ] 单击开文件/单击目录开合、标签上限提示、中键关闭、Ctrl+F 高亮与跳转可用
- [ ] 大文件打开被拦截并提示；dotfiles 开关即时生效
- [ ] i18n key 双端同现；UI 样式 token-bound、无原生控件外观（frontend-styles 自查）
- [ ] `pnpm run test:run` 全绿；`cargo test` 不受影响全绿
