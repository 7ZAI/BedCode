## 任务

扩展 `src/composables/useSessionWindows.ts`，新增代码面板窗口几何能力（单例内，按 sessionId 状态化）：

1. **`toggleCodePanel(sessionId)` / `openCodePanel(sessionId)` / `closeCodePanel(sessionId)`**
   - 展开：记录 pre-expand rect（outerPosition + outerSize，逻辑像素）；窗口向右扩大 **420 逻辑像素**（`setSize` + 位置不变）
   - 屏右钳制：扩大后右缘超屏幕 → 钳到剩余空间；剩余 < 300 逻辑像素 → **拒绝展开**（返回可提示的拒绝结果，不改任何窗口状态）
   - 收起：严格恢复 pre-expand rect
2. **展开态标记**：窗口状态增加 `codePanelOpen: boolean`；`openTerminalWindow` 不受影响
3. **贴靠联动复核（ADR 0023 Consequences）**：主窗口移动/缩放的跟随逻辑在展开态下不得把扩大后的窗口宽度重置回旧值——跟随只同步位置，宽度以展开态为准
4. 供 `TerminalWindowView.vue` 调用的返回接口：`codePanelOpen(sessionId)` / `toggleCodePanel` / 敞开后当前窗口几何查询（面板 UI 需要知道「终端视口固定宽度 = 展开前 innerWidth」）

## 验收标准

- [ ] 展开后窗口宽度 = 原宽 + 420（逻辑像素），位置不变；终端视口（前端侧）像素宽度在展开前后一致（契约：PTY 不重协商）
- [ ] 屏余 < 300 时拒绝展开且窗口状态无任何残留改动
- [ ] 收起恢复 pre-expand rect（含用户已拖宽的情况——拖宽部分被丢弃，这是 ADR 0023 显式语义）
- [ ] 展开态下主窗口移动跟随仍正确（不重置宽度）
- [ ] `pnpm run test:run` 全绿（如新增单测，composable 几何部分 mock `WebviewWindow`）
