## 任务

新增桌面端宿主命令域 `src-tauri/src/commands/code_viewer.rs`（内置功能，不经插件系统）：

1. **`list_code_dir(root: String, rel_path: String) -> Vec<CodeDirEntry>`**
   - `CodeDirEntry { name, is_dir, is_symlink, size, mtime, is_hidden }`；目录前排列
   - `rel_path` 空串 = 列根目录；非空 = root 下相对子路径
   - 懒加载单层返回（不许递归）
2. **`read_code_file(root: String, rel_path: String) -> CodeFileContent`**
   - `CodeFileContent { content: String, encoding: 'utf8' | 'gbk', truncated: bool }`
   - 防御性截断：1MB / 2 万行上限，超出截断且 `truncated = true`（前端已按条目 size 决定不自动打开，此处防绕过）
   - 编码：先 `std::str::from_utf8`，非法字节回退 GBK（`encoding_rs`）
3. **`stat_code_file(root: String, rel_path: String) -> { size, mtime }`**——自动重载轮询用（轻量，不读内容）
4. **路径安全（强制）**：`canonicalize` 拼接路径后校验在 canonicalize(root) 之内；`..` 逃逸、符号链接逃逸一律拒绝并返回 `AppError` 带清晰上下文；root 本身不存在也拒绝
5. `lib.rs`：模块声明 + invoke_handler 注册（`list_code_dir` / `read_code_file` / `stat_code_file`）
6. `Cargo.toml` 增加 `encoding_rs`
