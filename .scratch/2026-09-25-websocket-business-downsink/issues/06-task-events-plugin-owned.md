# 06: 任务事件归插件

**What to build:** 让任务状态、队列、定时任务和任务结果由 `terminal-session` 自己通过 bus/emit 发布与消费；宿主不再维护任务同步载荷或移动端专用广播逻辑。

**Blocked by:** 05 — 会话事件归插件

**Status:** ready-for-agent

- [ ] 任务状态、队列、预设和定时任务事件均由插件定义并发布。
- [ ] 跨插件消费者通过 bus 获取事件，桌面消费者通过 emit 获取前端事件。
- [ ] 事件载荷自足，宿主不按任务变体重建字段或解释状态。
- [ ] 任务域不再调用宿主 `broadcast_sync` 产品接口。
- [ ] 事件缺失、非法载荷、重复发布和消费者未订阅均有明确行为。
- [ ] 任务事件迁移后，任务功能与现有插件命令面保持一致。
