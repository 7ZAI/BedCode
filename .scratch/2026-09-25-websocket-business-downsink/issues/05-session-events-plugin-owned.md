# 05: 会话事件归插件

**What to build:** 让会话创建、状态、停止、移除等生命周期事件由 `terminal-session` 自己定义载荷并通过通用 bus/emit 发布；宿主只提供事件传输，不再解释会话事件或决定同步广播。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 会话生命周期生产者发布自足事件，桌面消费者能收到完整数据。
- [ ] 需要跨插件消费的事件使用 public bus topic；插件内部事件使用属主私有 topic。
- [ ] 事件不依赖宿主会话登记查询，不回查内核补字段。
- [ ] 事件发布失败有明确日志/结果，不伪造半成品通知。
- [ ] 会话事件生产路径不再调用宿主同步广播产品接口。
- [ ] 事件顺序、来源设备处理和缺失数据反例有行为测试。
