# 02: 连接上下文与脱敏认证身份

**What to build:** 让插件在处理端点连接时能够取得经过裁剪的连接/认证上下文，用于自己的设备和会话业务；宿主提供通用查询原语，但绝不把凭据或业务派生数据交给插件。

**Blocked by:** 01 — 通用插件端点骨架

**Status:** ready-for-agent

- [ ] 插件可按 endpoint/client 查询连接地址、连接时间、认证状态和脱敏身份信息。
- [ ] 查询结果不包含 JWT、session token、公钥、私钥、配对记录或会话数据。
- [ ] 端点属主可以查询，跨插件查询显式拒绝且不改变连接状态。
- [ ] `auth: none` 连接返回未认证上下文，不伪造身份。
- [ ] desktop WIT/SDK 契约、宿主权限门和 ABI 版本同步更新，旧产物按新 ABI 规则处理。
- [ ] 正常、拒绝、认证失败和上下文脱敏均有单元/集成测试。
