# 桌面端插件 UI 规格

Type: prototype
Status: resolved
Blocked by: 02, 03

## Question

桌面端文件传输插件的界面规格。依赖「宿主通用文件服务能力接口设计」（页面状态与能力钩子暴露的事件挂钩）。

已定框架：插件注册的标准入口（桌面 SDK 扩展点，需先调研桌面 SDK contributes 能力）→ 独立页面；双区布局（目录浏览 + 传输队列抽屉）；TailwindCSS + 宿主明暗主题；信息密度高（表格视图、右键菜单、拖拽发送如可行）；允许目录在插件设置区管理。

要敲定的：
- 浏览面板：面包屑 / 列表列（名称、大小、修改时间、类型图标）/ 多选发送交互 / 音乐电影文档的缩略或图标策略
- 传输队列抽屉：任务行布局（进度条、速率、剩余时间、暂停/继续/取消按钮）、整体状态摘要
- 设置区：允许目录列表的增删交互（走宿主 fs 授权弹窗）、并发数设置
- 同名被拒、断线待续传等异常态的呈现方式

产出：低保真线框（/prototype）+ 交互说明，供用户过目后写入 spec。

## Answer

用户从三个结构变体中选定 **Variant A —— 双栏工作台**（原型见 [prototypes/desktop-ui/index.html](../prototypes/desktop-ui/index.html)，`#A` 直达；三变体完整稿为一次性原型，不进生产分支）。

### 定稿布局

- **顶栏**：对端选择 pill（在线绿点 + 设备名）、面包屑（当前位置）、操作区：「下载所选 (N)」（主按钮）、「发送到手机…」、刷新、「设置」。
- **左栏（主区）**：对端允许目录浏览——表格视图：复选框多选、名称（类型图标）、大小、修改时间；支持文件夹进入/面包屑回退。
- **右栏（360px 常驻）**：传输队列，顶部状态汇总 chips（N 传输中 / N 排队 / N 失败 / N 同名被拒），下方任务卡：方向箭头 + 文件名 + 暂停/取消按钮 + 进度条 + 元信息行（已完成/总量、速率、剩余时间）。

### 状态呈现

- 传输中：蓝色进度条 + 速率/剩余时间
- 已暂停：琥珀色 chips + 进度条琥珀色 + ▶ 恢复
- 失败：红色 chips + 原因文案（如"远端文件已变化"）+「重新排队」
- 同名被拒：紫色 chips + 文案"目标目录已存在同名文件，无法上传"
- 排队：灰色 chips

### 遗留（不阻塞）

- 桌面插件 SDK 具体挂哪个扩展点（sidebar/toolbox view）属实现期勘察，记在雾区；本票只定页面本身的规格。
- 右键菜单/拖拽发送：A 变体未含，作为增强项留给实现期，非规格硬要求。
