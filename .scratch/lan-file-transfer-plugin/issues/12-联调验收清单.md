## 验收清单（执行顺序从上到下）

### A. 接收策略与批量批准

- [ ] **A1 ask 默认策略**：桌面向手机发送多文件 → 手机出现批应答对话框（前台）→ 点「接受全部」→ 桌面任务转「传输中」→ 文件落手机下载目录 → 双方历史出现 completed（方向：桌面 ↑ / 手机 ↓）。
- [ ] **A2 拒绝全部**：重复 A1 但点「拒绝全部」→ 桌面任务 rejected，文案「对方拒绝了传输」；手机无任务记录、无历史、无 toast。
- [ ] **A3 超时**：ask 模式发送后不操作，60s 后 → 桌面任务 rejected，文案「对方未响应，请求已超时」；手机批卡消失。
- [ ] **A4 超时配置生效**：手机设置超时 10s → 10s 未应答即超时；设置 600 生效；越界（9/601）被拒绝。
- [ ] **A5 accept 模式**：手机设置「直接接收」→ 桌面发送 → 无需应答直接传输；手机 toast「xx 正在向你上传 N 个文件」；3s 窗口内多个文件只弹一条（计数累加）。
- [ ] **A6 reject 模式**：手机设置「直接拒绝」→ 桌面发送 → 桌面任务 rejected，文案「对方设置了直接拒绝」；手机零打扰（无任务/无 toast/无历史）。
- [ ] **A7 策略切换即时生效**：传输前切换策略，下一次发送按新策略。
- [ ] **A8 反方向（手机→桌面）**：A1–A6 反方向各验一次（桌面为接收方：应用内横幅应答；手机为发送方）。特别验证：手机发送 → 桌面横幅「接受全部」→ 手机任务转传输中。

### B. 断线与边界

- [ ] **B1 等待同意时断线**：ask 发送后、应答前关闭接收端 App（或断 WiFi）→ 发送方任务 → rejected（timeout），重连后**不自动重发**。
- [ ] **B2 批准后断线重连续传**：批准后传输中关接收端 App → 重连 → 发送方自动续传（免问、免钩子），文件哈希一致。
- [ ] **B3 接收端重启**：pending 批不跨重启（发送方超时 rejected），重启后无残留批卡。
- [ ] **B4 多对端并发**（有第三端时）：两个发送方同时 ask → 两个批独立应答、独立超时。
- [ ] **B5 批内同名**：批中一个文件与接收端目标重名 → 该文件 rejected（duplicate-name），批内其他文件正常完成。

### C. 接收端任务与历史

- [ ] **C1 正在接收 tab**：传输中手机队列「正在接收」tab 出现接收任务（只可取消，无暂停/恢复）。
- [ ] **C2 取消单个接收任务**：接收中取消 → 发送方对应任务终态正确（取消/失败），其余文件继续。
- [ ] **C3 队列 4 tab 分类**：全部 | 正在发送 | 正在接收 | 历史 分类正确（发送/接收按发起方）。
- [ ] **C4 历史归档**：完成/失败/被拒/取消任务全部出现在「历史」tab（时间、方向 ↑/↓、文件名、大小、结果）；终态任务在队列内仍可 retry/remove。
- [ ] **C5 历史封顶**：制造 >200 条终态 → 最旧被淘汰；「清空历史」清空。
- [ ] **C6 打开所在文件夹**：历史/队列中 completed 且有本地文件的任务 → 桌面「打开所在文件夹」定位文件；手机「系统查看器打开文件」。

### D. Kotlin 通知（仅移动端）

- [ ] **D1 后台批应答**：手机 App 退后台/锁屏，桌面发送（ask）→ 系统通知带「接受全部 / 拒绝全部」→ 点「接受全部」→ 桌面任务转传输中；点「拒绝全部」→ 桌面 rejected。
- [ ] **D2 通知清理**：批解决后（应答或超时）通知自动消失；重复请求各自独立通知。
- [ ] **D3 通知文案**：zh/en 双语言（跟随系统语言）。

### E. v1 回归

- [ ] **E1 下载**：手机→桌面拉取、桌面→手机拉取均正常；进度/速率/暂停/恢复。
- [ ] **E2 断点续传**：10GB 级文件 30%/60%/90% 强制中断 → 恢复后续传完成，哈希一致（spec §12 验收项 3）。
- [ ] **E3 同名即拒（单文件）**：目标已存在 → rejected duplicate-name 文案。
- [ ] **E4 对端在线状态**：上下线 pill/角标即时刷新；对端无共享目录提示。
- [ ] **E5 设置**：roots/downloadDir/concurrency 增删改即时生效；并发数 1–8。
- [ ] **E6 性能抽查**（可选）：单大文件吞吐 ≥ 80% × min(T, D)（spec §12 验收项 1），内存增长 ≤ 100MB。
