# 03 — 硬黑名单层接入扫描

**What to build:** 扫描结果自动排除硬黑名单命中的文件（浏览器 Cookies / Login Data / Web Data / Bookmarks / History / 应用配置与本地数据库等）：即使被某条清理目标的模式命中也强制跳过，结果页展示「N 个文件已按保护规则跳过」。双层防御的第二层——规则清单管删什么，黑名单管绝不删什么。
