# 模型分发

Label: wayfinder:issue
Type: grilling
Status: resolved

## 决策

**全打包 + 可删除**：PP-OCRv4 模型（~17MB）打进 APK assets，首次识别时惰性解压到 app 数据目录；插件设置区提供「删除模型释放空间」+「从 APK 恢复模型」（重解压，无需网络）。onnxruntime `.so`（每 ABI 一份 15-25MB）随 APK 不可删。

## 体积账（universal APK，4 ABI）

OCR 部分总增量约 +60~80MB：模型 17MB（ABI 无关，可删）+ onnxruntime `.so` ×4（不可删）。

## 被拒方案

- **b. 模型首启下载**（APK 只 +.so）：离线承诺打折，首启依赖网络——v1 拒绝。
- **仅打包不可删**：用户无法释放空间——拒绝。
