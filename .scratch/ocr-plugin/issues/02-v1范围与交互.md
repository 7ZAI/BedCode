# v1 范围与交互

Label: wayfinder:issue
Type: grilling
Status: resolved

## 决策

- 识别对象：印刷体中英混排（PP-OCRv4 ch 模型天然覆盖），不限版式（文档/书页/屏幕/票据统一按文本行输出）。
- 不做：手写体、表格结构还原、公式（PP-OCRv4 只输出文本行 + 位置框；表格/公式结构还原属 PP-Structure 系，手机跑不动）。
- 输入：**相册选图 + 相机拍照双入口**（v1 都要）。
- 交互：单张串行识别；结果页 = 文本行列表 + 「复制全文」+ 行级点击复制；**无历史、无批量**。

## 理由

行级 box 是 PP-OCR 白送的副产品（成本约零），行级复制是 20% 成本 80% 价值；批量与历史留给 v1.1/v2（随「收藏/导出」一起设计）。
