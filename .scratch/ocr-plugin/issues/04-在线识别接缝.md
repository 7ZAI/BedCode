# 在线识别接缝

Label: wayfinder:issue
Type: grilling
Status: resolved

## 决策

在线识别（v2）采用**供应商无关的适配器模式**（与桌面端 AI 供应商适配层同构，语言参照 `docs/adr/0010-provider-adapter-frontend-layer.md`）：宿主命令带 `engine` 字段（`"offline"` 默认；v2 加 `"online:<provider>"`），Rust 侧引擎抽象为 trait（offline 实现 / 未来 online 实现）。v1 **不实现任何在线逻辑**，只留路由与类型；插件 UI 的引擎选择器 v1 只渲染「离线」单选项。

## 理由

用户明确「可以接入任意一家在线 OCR 供应商」（百度/阿里/腾讯/自建均可）——接口必须供应商中立，不能锁死某家。v1 只留缝，避免过度设计。
