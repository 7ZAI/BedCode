# 07 — 识别流水线（det/cls/rec + 行排序 + 置信度）

**What to build:** 真正的 OCR 能力：一张 RGBA8 图片 → 文本行列表（按阅读顺序、原图坐标系 bbox、逐行置信度 0~1、空文本行剔除）；首次识别惰性加载引擎（解压 + 建 3 个 ort session）并常驻缓存；识别全程 `spawn_blocking` 后台线程；并发请求单飞串行排队。实现依据为 spec §4.3 + §8 性能目标。用户可感知：`recognize` 返回正确文本行，第二次识别不再等模型加载，识别中再触发排队不崩。

**Blocked by:** 06（需要模型文件 + ort session 才能推理）

**Status:** ready-for-agent

- [ ] PP-OCRv4 三段流水线（det → cls → rec）用 ort session 推理打通
- [ ] 行排序：det 输出自上而下、行内从左到右（阅读顺序）；bbox 换算回原图坐标系（Kotlin 解码尺寸）
- [ ] 空文本行剔除；`confidence` 为 rec 逐行置信度（0~1）
- [ ] `cargo test` 通过：合成 RGBA 图测预处理（灰度/归一化/det 缩放）与排序/剔除/bbox 换算逻辑（模型推理留真机验证）
- [ ] 惰性加载 + 常驻：首次 `recognize` 初始化（解压+建 session），成功后缓存；第二次不再加载（spec §10 清单第 6 项依据）
- [ ] 单飞队列：并发 `recognize` 串行执行不崩溃（spec §10 清单第 7 项依据）；引擎加载失败返回带原因错误
- [ ] 真机：中/英/混排样张识别正确；首次 ≤5s、稳态单张 ≤3s（spec §8）
