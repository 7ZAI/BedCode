## Comments

- **WIT/SDK**：`host-session` 同 v19 函数级追加 `annotate`（权限 `session:write`）与
  `connections-list`（权限 `session:read`），ABI 不 bump（desktop 19 / mobile 11 双端偏离不变）。
  SDK `HostSession` trait + `WasmHost` 各加 `session_annotate` / `connections_list`。
- **内核注解槽**（`SessionManager`）：`annotations: session-id → map<string,string>` 不透明
  键值对，只搬运透传、绝不解释键名（spec D5）；`annotate_session`（会话存在才落槽，未知
  会话 false）+ `session_annotations` 读；会话移除/停机连带清理。expand 期与旧任务字段
  （`SessionInfo.task_*`）并存，DTO/同步事件零改动；`list-sessions` / `get` 原语回执加
  `annotations` 透传字段（与 `canonicalRenderer` 同形超集，wire DTO 不受影响）。
- **属主口径**（如实记录）：注解槽为扁平 map（D5 形状），「属主」= `session:write` 权限门
  （与 `close`/`create` 同边界的属主边界）+ 会话存在性 + 写入按调用方 plugin_id 留日志
  （值只记长度不落明文，AGENTS §8）；未做按插件命名空间隔离——多插件争写同一键的隔离
  属未来裁决（ADR 0022 范畴），本票不臆造。
- **插件**（`plugins/session`）：新 `devices` 域——注解槽写面（`session.annotate` 命令 +
  `annotate` api）+ 设备派生视图（`session.devices.connect-list` 命令 + `devices-connect-list`
  api）：在线判定（连接指纹 ↔ 活跃配对）+ 真实会话数（正统渲染端 deviceName 归属口径，
  模块文档写明确认）+ 任务状态合并（注解槽 `taskStatus`/`taskReason`）；撤销不合并 paired
  但连接行保留（不新增踢下线语义，行为测试锁定）。manifest api 19→21，五同步点全落。

  宿主旧路径（原始连接 + 0），无单点；映射保持 `DeviceConnectionInfo` 逐字同形，前端零改动。
- **验证**：内核双写一致性对照（槽与旧字段并存互不干扰、移除清槽）+ host_impl 权限/参数/
