# 01: 设置分组扩展点（内核 UI 能力 A）

**父规格:** `.scratch/2026-09-19-terminal-session-plugin/spec.md` D6

**What to build:** 插件获得「往宿主设置页贡献一个分组」的正式落点：贡献方注册一个分组（标题、图标、排序值、组件），设置页把宿主内置分组与注册表分组按排序值合并渲染，像素与交互与今天一致。此阶段设置页内容不变——内置分组仍由宿主提供，只是改走同一套渲染管线。

**Blocked by:** None (can start immediately)

**Status:** done（2026-09-19；桌面 `pnpm run test:run` 73 files / 708 tests 全绿、根 `pnpm exec eslint .` 0 error，实施记录见 Comments）

- [x] 插件上下文新增分组注册 API，返回值可释放（Disposable），停用即摘除
- [x] 新权限位 `ui:settings` 落三同步点：SDK 权限常量、前端合法权限集合与 `ui.*` API 映射、打包 CLI 的 manifest 权限校验（无 host_impl 权限门那一路）
- [x] 设置页改为「内置分组 + 注册表分组」按 `order` 合并渲染；缺省排序值行为与既有贡献面一致
